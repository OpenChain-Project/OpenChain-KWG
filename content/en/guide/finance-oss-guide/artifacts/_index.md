This guide provides four ready-to-use artifacts along with the main text. Where the main text
explains "what to do and why," the artifacts fill in "in what form to record it." Each artifact is
meant to be adapted to your organization's situation.

| Artifact | Use |
|------|------|
| [Self-Check Workbook](./1-workbook/) | Combines check items, ISO verification materials, and compliance status, owner, and deadline in a single sheet to find the gaps in your program |
| [Policy and Procedure Templates](./2-policy-templates/) | Provides outlines for a finance-specific policy, an import procedure, a usage approval form, and a self risk assessment report for network separation exceptions |
| [Audit Evidence List](./3-audit-evidence/) | Organizes, as a checklist, the evidence required in internal and external audits and supervisory inspections and where it is kept |
| [Tool Setup Recipe](./4-tool-recipe/) | Provides an example of setting up and integrating on-premises SBOM and vulnerability tools in a closed network with docker-compose |

{{% alert title="How to use" color="info" %}}
The artifacts supplement the existing [policy and procedure templates](../../templates/) guide for
the financial context. Use the existing templates for general practice forms, and use these
artifacts together with them for items specific to the financial sector (import control, risk
assessment for network separation exceptions, and SBOM requirements for outsourcing).
{{% /alert %}}
