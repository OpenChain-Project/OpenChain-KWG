Identification: Finding All the Open Source You Use

Audit Evidence List

Identifying and Resolving Issues: Vulnerabilities and Licenses

  2. Financial Open Source Guide
  3. 3. Identify and Resolve Issues

Tool Setup Recipe

A docker-compose example and integration procedure for setting up SBOM generation and continuous vulnerability monitoring in an on-premises closed network environment. It shows the flow of creating SBOMs with cdxgen and registering them in Dependency-Track.
